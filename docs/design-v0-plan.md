## 页面清单（8 主题 ≈10 屏）

1. **菜谱库（首页）**：搜索（菜名 / 食材合一）、菜系筛选、内置 / 自家区分、收藏入口、当前空间名
2. **菜谱详情**：封面、份量 / 人数切换与换算、配料表（按主料 / 辅料 / 调味料分组）、版本切换（自家菜）、开始做菜、来源标记（"复制自内置 · XX"）
3. **做菜引导**：步骤勾选、步骤计时器、配料速查（带换算）、结束 → 记一笔
4. **做菜记录**：列表 + 单条编辑（日期默认今天可改、菜谱 / 版本可选、备注、本次配方可改）
5. **食材反查**：食材按主料 / 辅料分组多选、默认勾常备、当次增减
6. **反查结果**：只列"主料 + 辅料全齐备"的菜，点击进详情
7. **常备食材维护**：从食材字典挑 / 去，与反查页默认联动
8. **菜谱录入 / 编辑表单**：基本信息 + 配料行编辑器 + 步骤行编辑器
9. **我的**：当前空间、成员、分享卡片入口、收藏 / 记录 / 常备入口；含"通过卡片加入"确认屏
10. **收藏**：个人收藏列表，可取消

## 关键交互默认（G4 · 临时）

1. 做菜引导 = 单屏纵向步骤列表 + 点按勾选 + 当前步高亮；不翻页；常亮屏默认开
2. 计时器 = 每步可选挂时长，引导页一键启动，到点视觉提醒（不接系统通知）
3. 搜索 = 顶部单搜索框（菜名 / 食材合一）+ 菜系标签筛选
4. 记录日期 = 默认今天，可改
5. 常备入口 = 反查页"管理常备" + 我的页入口（两处）
6. 新空间预置常备 = 预置 10–15 条高频主辅料（调味料不入，反查不参与）

> 以上为设计用临时默认；正式决策留在需求划分阶段，改动时回头同步设计。

## 内容与数据约定

- **配方数字全真实**：用量 = 数字 + 单位，或特殊值"适量"（不参与换算）。
- **单位表（设计默认，正式清单留到需求划分）**：g / ml / 个 / 勺 / 碗 / 斤 / 两 / 根 / 棵 / 片 / 块 / 把。
- **反查规则真实**：调味料不参与匹配、界面不出现；默认勾选常备；结果 = "主料 + 辅料全齐备"的菜。墨刀原型没法真算，用**多状态画板**演示结果的增减（默认常备 / 取消"五花肉" / 只勾"鸡蛋、番茄"）。
- **食材字典**：覆盖 7 道样本菜的全部主辅料 + 常见家常食材，共 ≈25–35 条；录入时可"新建食材"。
- **样本菜（可改）**：内置 6 道——宫保鸡丁（川 · 30 分钟 · 中等）、麻婆豆腐（川 · 25 分钟 · 简单）、红烧肉（浙 · 90 分钟 · 中等）、清蒸鲈鱼（粤 · 25 分钟 · 中等）、番茄炒蛋（家常 · 10 分钟 · 简单）、青椒土豆丝（家常 · 15 分钟 · 简单）；另加 **自家菜 1 道**「番茄炒蛋（我家版）」——用来演示"复制自内置 · 番茄炒蛋"来源标记、编辑入口与版本切换（内置菜只读，没有这三样）。
- **图片**：封面用食物类图片（墨刀 AI 填充或图库替换）；做菜记录不配图，原型阶段不做自制素材。
- **不做的**：加载 / 错误态；除菜谱库、记录外的空态；家庭共享收藏；变更记录查看界面。

## 生成路线图

| 批次 | 内容 | 预计条数 |
| --- | --- | --- |
| 0 · 地基 | 全局样式 + 通用件 + 首页 | 2–3 |
| 1 · 做菜链路 | 详情 → 引导 → 记一笔 → 记录列表 | 3–4 |
| 2 · 反查链路 | 反查 → 结果 → 常备维护 | 2–3 |
| 3 · 录入 | 表单骨架 → 配料 / 步骤编辑器 | 2–3 |
| 4 · 外围 | 我的 / 空间 + 收藏 + 加入确认 | 2 |
| 5 · 走查 | 串联跳转 + 空态 + 统一微调 | 1–2 |

次序逻辑：样式与通用件先行（后面所有屏复用它们）→ 主链路（做菜先于反查：反查结果要跳的详情页在前一批已存在）→ 孤立表单 → 外围 → 集中走查。

### 执行要点

- 提示词直接粘贴给**墨刀 AI**（"输入需求生成原型 / 设计稿"入口均可）；每批尽量在**同一个会话里继续对话**（墨刀 AI 支持对话式改稿）；若必须新开会话，先声明"沿用项目已生成页面的视觉样式，不要重做"。若弹出"需求确认问题"，优先回答页面范围与业务规则；入口名称以工作台实际为准。
- 每批的首条提示已含通用约束（下方提示块可直接整段复制）；一次能出多页也**只推进 1–2 屏**，先把首屏调到位，再补相邻屏、再改稿。
- 提示词写法 = 缩小版需求说明：页面清单与入口、布局结构、真实字段与示例数据（配料数字必须真）、状态、视觉规范都写清；数据和状态写死一点，返工最少。
- 生成后先自己过一遍（能点、不溢出、色彩没跑偏、无英文占位），重点页用墨刀编辑器微调；tabBar、菜谱卡等通用件**做成组件复用**，避免逐页改。
- AI 不一定接好全部跳转：验收时列出"没接上的跳转清单"，在墨刀编辑器里选中元素手工配置交互（点击 → 目标页面）。
- 预览与验收：编辑器里按移动画板（≈390px）走查；终验用墨刀**手机预览（分享链接 / 二维码）**在真机上点一遍。
- 每批跑完再进下一批；返工轮次算进额度预算（墨刀 AI 次数与账号方案有关，吃紧再升档，不影响批次结构）。
