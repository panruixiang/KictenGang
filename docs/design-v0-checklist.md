## 每批关闭条件（勾完才算完成）

### 批次 0 · 地基

- [ ] 项目骨架 + 设计变量（token）落地
- [ ] 通用件齐全：手机壳 / tabBar / 菜谱卡 / chip / 按钮 / 列表行
- [ ] 首页可看：7 张样本卡（6 内置 + 1 自家）、搜索框与菜系筛选在位
- [ ] 预览宽度调成 ≈390px 无破版
- [ ] **token 实际值回填**到 plan 文档的表格

### 批次 1 · 做菜链路

- [ ] 详情：份量 / 人数切换 → 配料实时换算（"适量"不变并标注）
- [ ] 详情：自家菜显示"复制自内置 · XX" + 编辑入口 + 版本切换（内置菜没有）
- [ ] 引导：步骤勾选、当前步高亮、计时器启动 / 暂停 / 到点态
- [ ] 记一笔：日期 / 关联菜谱 / 版本 / 备注 / 本次配方可改
- [ ] 记录列表能看到刚保存的那条；整链可从首页点到底、再返回

### 批次 2 · 反查链路

- [ ] 反查页只出现主料 / 辅料；默认勾上常备
- [ ] 真算：取消"五花肉"→ 红烧肉消失；只勾"鸡蛋、番茄"→ 只剩番茄炒蛋（内置 + 我家版两张卡）
- [ ] 常备维护页勾选与反查页默认联动
- [ ] 结果卡能跳详情

### 批次 3 · 录入

- [ ] 基本信息 + 份量预填 2 人份 / 可清空并提示不换算
- [ ] 配料行：增删移、食材选择器（含新建食材）、单位下拉（g / ml / 个 / 勺 / 碗 / 斤 / 两 / 根 / 棵 / 片 / 块 / 把）、"适量"开关
- [ ] 步骤行：增删排序、可选计时
- [ ] 长表单手机视口无溢出、可滚动

### 批次 4 · 外围

- [ ] 我的页：空间卡、成员、入口行（收藏 / 记录 / 常备 / 切空间）
- [ ] 分享卡片预览 + 加入确认屏
- [ ] 收藏页可取消收藏

### 批次 5 · 走查

- [ ] 全部跳转点通（含返回）
- [ ] 两处空态：菜谱库、记录
- [ ] 视觉抽查：颜色 / 圆角 / 字体 / 间距无跑偏
