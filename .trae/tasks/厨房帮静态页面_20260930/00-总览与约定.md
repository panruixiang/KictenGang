# 厨房帮 · 前端静态页面开发 · 总览与约定

> 本任务集来自 [design-v0-plan.md](../../../docs/design-v0-plan.md)（原"墨刀原型生成计划"）的改道：**不再使用墨刀**，改为按 uni-app 工程开发**前端静态页面**。
> 计划文档继续作为页面内容与数据规格来源（墨刀操作与提示词部分作废）；术语以 [CONTEXT.md](../../../CONTEXT.md) 为准；需求决策见 [REQUIREMENTS.md](../../../docs/REQUIREMENTS.md)。

## 目标与定位

- 用 uni-app（Vue3 + TypeScript）实现 MVP 主流程的静态页面：数据为写死的真实 mock，交互按设计规则真实实现（内存状态、刷新重置），不接后端 / 云开发。
- 页面兼作视觉基准与后续实现骨架——以后接微信云开发、出小程序不用重写（对齐 ADR-0003）。

- `00-总览与约定.md`（本文）：全局约定与执行方式
- `tickets/`：14 个工单（`{NN}-{slug}.md`），按依赖顺序编号

## 技术形态与工程结构

- 工程位置：`client/`（uni-app 标准结构；仓库根保留 docs / .trae / CONTEXT.md）
- 脚手架：`npx degit dcloudio/uni-preset-vue#vite-ts client`（Node ≥ 18，Vue3 + Vite + TS）
- 常用命令：`npm run dev:h5`（浏览器预览）、`npm run build:h5`（构建）
- 目录约定：

```text
client/src/
  pages/       页面（tabBar 四页 + 其余页面）
  components/  通用组件（RecipeCard / Chip / 按钮 / 列表行…）
  mock/        mock 数据（真实内容，见下）
  store/       内存状态（Vue reactive 模块，不持久化）
  utils/       换算等工具
  types/       TypeScript 类型
  static/      图片 / tabBar 图标
  styles/      全局 SCSS 变量与样式
```

- 导航：全局 `navigationStyle: custom`，各页自绘标题区（含返回）；尺寸用 rpx（基准 750rpx ≈ 390px 逻辑宽）。

## 内容与数据约定（写死进 mock）

- 样本菜 7 道：宫保鸡丁（川 · 30 分钟 · 中等）、麻婆豆腐（川 · 25 分钟 · 简单）、红烧肉（浙 · 90 分钟 · 中等）、清蒸鲈鱼（粤 · 25 分钟 · 中等）、番茄炒蛋（家常 · 10 分钟 · 简单）、青椒土豆丝（家常 · 15 分钟 · 简单）——6 道内置、只读；自家菜 1 道「番茄炒蛋（我家版）」：带来源小字"复制自内置 · 番茄炒蛋"、版本（默认版 / 少糖版）、可编辑。
- 配方数字全真实：用量 = 数字 + 单位，或特殊值"适量"（不参与换算）。
- 单位表：g / ml / 个 / 勺 / 碗 / 斤 / 两 / 根 / 棵 / 片 / 块 / 把。
- 食材字典 20+ 条：覆盖 7 道样本菜的主料、辅料与调味料 + 常见家常食材；反查页只显示主料 / 辅料。
- 反查规则真实：调味料视为默认有、不参与匹配；结果 = 主料 + 辅料全齐备的菜。
- 常备食材默认 12 条：鸡蛋、番茄、土豆、五花肉、鸡腿肉、豆腐、花生米、鲈鱼、青椒、蒜、葱、姜。
- 份量换算：比例 = 目标人数 ÷ 菜谱份量（份量录入时预填 2 人份）；"适量"不换算并标注；份量未填时不做换算。
- 封面图：真实食物照片风格，图片落盘 `src/static/cover/`（不使用灰块占位）。
- 空间与记录：当前空间"老张家的厨房"；记录含"随手记"示例（不挂菜谱、无版本）。

## 交互深度与边界

- 交互真实实现：搜索 / 筛选、收藏切换、份量换算、步骤勾选与计时、反查勾选与结果过滤、常备联动、表单增删移等；状态放内存 store，刷新回默认。
- 不做：加载 / 错误态；空态只做两处（菜谱库、记录）；不做持久化、不接接口。
- 代码注释用中文；组件值传递 props，状态变更通过内部事件（emit）向上传递。
