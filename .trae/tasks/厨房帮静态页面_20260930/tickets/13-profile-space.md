# 13 — 我的与空间

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** "我的" tab：看清当前空间与成员，进入收藏 / 记录 / 常备 / 切空间；还能演示"邀请家人"的分享卡片与"通过卡片加入"的确认屏。

**Blocked by:** 工单 06（记录列表）、工单 09（常备食材维护）、工单 12（收藏）

**Status:** ready-for-agent

## 规格要点

- 底部 tabBar"我的"选中态。
- 空间卡：当前空间名"老张家的厨房" + 成员头像组（彩色圆 + 首字即可）+ "邀请家人"按钮。
- 入口行：我的收藏（→ 12）、我的记录（→ 记录 tab）、常备食材（→ 09）、切换空间（示例两个空间，可切换示意）。
- 分享卡片预览：点"邀请家人"弹出微信分享卡片样式（空间名 + 一句邀请语"一起来存菜谱、记做菜吧" + 小程序卡片外观）。
- 加入确认屏：模拟从分享卡片进入——"XX 邀请你加入『老张家的厨房』"，主按钮"加入"、次按钮"暂不"。

## 验收标准

- [ ] 空间卡、成员头像组、四个入口行齐全；收藏 / 记录 / 常备的入口均可点达
- [ ] 分享卡片弹层与加入确认屏可演示，加入 / 暂不均有去向
- [ ] `npm run build:h5` 通过
