# 03 — 菜谱详情

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 从首页卡片进入详情页：看清这道菜的全部信息（封面、菜系、耗时、难度、份量、分组配料、步骤预览），可切换人数看换算，可点"开始做菜"；自家菜还能看到来源、编辑入口与版本切换。

**Blocked by:** 工单 02（菜谱库（首页））

**Status:** ready-for-agent

## 规格要点

- 示范菜：内置菜"宫保鸡丁"；另加自家菜「番茄炒蛋（我家版）」同页双态（可做两个入口进入）。
- 顶部：大封面图 + 左上角返回。
- 信息行：菜名 + 菜系标签"川" + "30 分钟" + "中等"。
- 份量换算：默认"2 人份"；1 / 2 / 3 / 4 / 6 人可切换、当场换算（比例 = 目标人数 ÷ 菜谱份量；"适量"不变并标注"不换算"）。换算逻辑抽到 `src/utils/`（工单 04、05 复用）。
- 配料区按 主料 / 辅料 / 调味料 三组：
  - 主料：鸡腿肉 300g、花生米 50g
  - 辅料：干辣椒 8 个、葱 1 根、蒜 3 瓣
  - 调味料：生抽 2 勺、老抽 1 勺、醋 2 勺、糖 1 勺、料酒 1 勺、盐 适量、淀粉 适量
- 步骤预览：编号 1–6 的只读列表，真实可操作的中文步骤（大纲：腌肉 → 调碗汁 → 炒香花生 → 爆香干辣椒 → 炒鸡丁 → 合炒收汁）。
- 底部固定主按钮"开始做菜" → 做菜引导（工单 04）。
- 自家态（番茄炒蛋（我家版））：菜名下小字"复制自内置 · 番茄炒蛋" + "编辑"入口（→ 录入表单）+ 版本切换（默认版 / 少糖版）。内置菜只读，没有来源、编辑、版本这三样，其余样式完全一致。

## 验收标准

- [ ] 切到 4 人份时用量按比例放大；"适量"不变且带"不换算"标注
- [ ] 配料三组与步骤 1–6 展示正确
- [ ] 双态差异（来源小字 / 编辑 / 版本切换）正确
- [ ] "开始做菜"可跳引导；`npm run build:h5` 通过
