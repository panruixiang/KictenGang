# 05 — 记一笔（做菜记录编辑）

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 做完菜点"记一笔"进入记录编辑：确认日期（默认今天）、关联的菜谱与版本、写一句备注，并可就地改"本次配方"；保存后进记录列表。

**Blocked by:** 工单 04（做菜引导）

**Status:** ready-for-agent

## 规格要点

- 日期：默认今天，可改（日期选择器）。
- 关联菜谱："宫保鸡丁"，可清除（清除后即为"随手记"态）。
- 关联版本：可选，"默认版"为选中态。
- 备注：多行输入框（写一句示例备注）。
- 本次配方：展示这份配方的配料表副本；配料行可就地改（如点击用量行内编辑数字）——示范一行改过的样子（数字变了 + 行尾小标记"这次改过"）。
- 底部主按钮"保存"：写入内存记录 store（与工单 06 同源），保存后进记录列表（工单 06）。

## 验收标准

- [ ] 日期默认今天且可改
- [ ] 清除关联菜谱后呈"随手记"态；版本可选可清除
- [ ] 本次配方的改过行展示"这次改过"标记
- [ ] 保存后有数据落进记录 store；`npm run build:h5` 通过
