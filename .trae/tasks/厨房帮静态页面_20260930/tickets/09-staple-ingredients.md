# 09 — 常备食材维护

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 维护"我家平时就有的食材"清单：从食材字典里挑或去掉，反查页的默认勾选跟着这份清单走。

**Blocked by:** 工单 07（食材反查）

**Status:** ready-for-agent

## 规格要点

- 入口：反查页"管理常备" + "我的"页入口（工单 13 接入）。
- 顶部一句话说明："常备 = 家里平时就有的食材；调味料默认视为有，无需维护"。
- 全部主料 / 辅料分组浏览，带搜索框（按食材名过滤）。
- 已加入常备的默认勾选（与反查页一致，12 条）：鸡蛋、番茄、土豆、五花肉、鸡腿肉、豆腐、花生米、鲈鱼、青椒、蒜、葱、姜。
- 勾选 = 加入常备、取消 = 移出；选中态清晰；改动与反查页默认勾选同源联动（同一 store）。

## 验收标准

- [ ] 默认勾选与反查页完全一致（12 条）
- [ ] 搜索可用；勾选增删同步到 store
- [ ] 回到反查页可见联动；`npm run build:h5` 通过
