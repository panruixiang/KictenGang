# 04 — 做菜引导

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 点"开始做菜"进入引导页：照着步骤一步步做——点按勾选、当前步高亮、需要时给某一步计时，随时速查换算后的配料；全部做完出现"记一笔"。

**Blocked by:** 工单 03（菜谱详情）

**Status:** ready-for-agent

## 规格要点

- 顶部：菜名"宫保鸡丁" + "几人吃"选择器（1 / 2 / 3 / 4 / 6，当前 2 人），与配料速查换算联动。
- 配料速查：默认收起成一行，展开后显示换算后的配料（复用工单 03 的换算工具）。
- 步骤：单屏纵向列表；每步 = 序号 + 步骤文字 + "计时"按钮；点按整步即勾选完成（文字划线变灰）；当前步高亮。
- 计时态：某一步展示倒计时（如 04:59，带暂停 / 重置按钮；真实倒计时逻辑，样例步骤可挂 5 分钟）；另一步展示"时间到"的提醒样式；到点只做视觉提醒，不接系统通知。
- 一行提示："做菜中保持屏幕常亮"（可调用 `uni.setKeepScreenOn`，H5 端忽略即可）。
- 底部按钮"记一笔"（步骤全部完成后出现）→ 记一笔（工单 05）。

## 验收标准

- [ ] 勾选（划线变灰）与当前步高亮正确
- [ ] 倒计时启动 / 暂停 / 重置可用，到点有提醒样式
- [ ] 配料速查展开后用量按人数换算
- [ ] 全部完成后出现"记一笔"并可跳转；`npm run build:h5` 通过
