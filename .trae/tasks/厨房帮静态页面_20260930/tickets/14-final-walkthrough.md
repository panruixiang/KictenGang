# 14 — 走查与收尾

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 把整套页面当成一个原型走一遍：所有入口点得通、退得回；两处空态齐备；视觉对照设计 token 做最后一轮统一微调。

**Blocked by:** 工单 08（反查结果）、工单 11（录入表单 · 配料与步骤编辑器）、工单 13（我的与空间）——即全部前置完成后

**Status:** ready-for-agent

## 规格要点

- 串联核对（要真点通、能返回）：
  - 做菜链路：首页卡 → 详情 → 开始做菜 → 引导 → 记一笔 → 保存 → 记录列表
  - 反查链路：反查 → 找找能做什么 → 结果 → 卡 → 详情
  - 外围：我的 → 收藏 / 记录 / 常备食材 / 加入确认；详情 → 编辑 → 录入表单
- 两处空态齐备：菜谱库（新空间：只有内置菜 + "把常做的菜录进来吧"）、记录列表（"还没有记录，做完一道菜记一笔"）。
- 统一微调：卡片间距、文字溢出、tabBar 选中态、按钮宽度一致性；色彩与圆角对照 token 再抽查一遍（#FAF8F5 底 / #E8590C 主 / 圆角 12–16px）。
- 问题清单就地修复（如涉及此前工单的页面，直接回改对应文件）。

## 验收标准

- [ ] 两条主链路与外围入口全部可点通、可返回，无死链
- [ ] 两处空态可演示
- [ ] 视觉抽查无跑偏（颜色 / 圆角 / 字体 / 间距）
- [ ] 关键页面在手机浏览器 H5 预览走一遍无卡点；`npm run build:h5` 通过
