# 08 — 反查结果

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 看"现在能做什么"：按真实规则即时列出主料 + 辅料全齐的菜；勾选一变，结果列表跟着变；点卡片进详情。

**Blocked by:** 工单 03（菜谱详情）、工单 07（食材反查）

**Status:** ready-for-agent

## 规格要点

- 规则（真实计算，非静态画板）：调味料一律视为有；一道菜入选 = 它的全部主料与辅料都在已勾选集合里；内置菜与自家菜各自成卡（番茄炒蛋会出现两张）。
- 核对用配料数据（mock 必须一致）：
  - 宫保鸡丁 = 主料 鸡腿肉、花生米 / 辅料 干辣椒
  - 麻婆豆腐 = 主料 豆腐 / 辅料 蒜
  - 红烧肉 = 主料 五花肉 / 辅料 姜、葱
  - 清蒸鲈鱼 = 主料 鲈鱼 / 辅料 姜、葱
  - 番茄炒蛋（含我家版）= 主料 鸡蛋、番茄
  - 青椒土豆丝 = 主料 土豆、青椒
- 必须自测通过的三个场景（由真实勾选驱动）：
  1. 默认常备 12 种 → 6 张卡：番茄炒蛋（内置）、番茄炒蛋（我家版）、青椒土豆丝、红烧肉、麻婆豆腐、清蒸鲈鱼；宫保鸡丁因缺"干辣椒"不出现
  2. 取消勾选"五花肉" → 红烧肉消失，剩 5 张卡
  3. 只勾"鸡蛋、番茄" → 只剩两张番茄炒蛋卡
- 卡片复用 RecipeCard；点击进入菜谱详情（工单 03）。
- 从反查页进入时可回退调整勾选，结果随勾选即时刷新。

## 验收标准

- [ ] 三场景结果与核对数据完全一致（含宫保鸡丁不出现）
- [ ] 结果随勾选变化即时更新
- [ ] 卡片可跳详情；`npm run build:h5` 通过
