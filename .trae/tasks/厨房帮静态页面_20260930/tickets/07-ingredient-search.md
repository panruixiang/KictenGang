# 07 — 食材反查

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 反查 tab：从"家里有什么"出发勾食材——默认勾上常备 12 种，可当次增减、可清空；点"找找能做什么"看结果。

**Blocked by:** 工单 02（菜谱库（首页））

**Status:** ready-for-agent

## 规格要点

- 顶部：已选数量（如"已选 12 种"，随勾选实时变）+ "管理常备"入口（→ 工单 09）+ "清空"。
- 食材多选列表：按 主料 / 辅料 两组；每行 = 食材名 + 勾选（选中 = 卡片变色 + 对勾）；**调味料不出现**（视为家里默认有）。
- 食材字典（下拉 20 条为必须，可按需再补几条常见食材）：
  - 主料组：鸡腿肉、五花肉、牛里脊、鲈鱼、鸡蛋、豆腐、土豆、番茄、青椒、花生米、虾仁
  - 辅料组：干辣椒、葱、姜、蒜、香菇、胡萝卜、黄瓜、白菜、南瓜
  - 字典另含调味料条目（供录入表单使用），反查页不显示。
- 默认勾选"我家常备"（示例态）：鸡蛋、番茄、土豆、五花肉、鸡腿肉、豆腐、花生米、鲈鱼、青椒、蒜、葱、姜（共 12 条已选）；勾选状态存 `store`（与工单 09 常备维护同源联动）。
- 底部主按钮"找找能做什么" → 反查结果（工单 08）。

## 验收标准

- [ ] 两组列表只出现主料 / 辅料；默认已选 12 条
- [ ] 勾选 / 取消 / 清空实时更新"已选 N 种"
- [ ] "管理常备"可跳 09；"找找能做什么"可跳 08
- [ ] `npm run build:h5` 通过
