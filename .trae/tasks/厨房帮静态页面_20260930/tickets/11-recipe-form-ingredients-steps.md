# 11 — 录入表单 · 配料与步骤编辑器

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 表单的后半段（重点）：一行行加配料、一步步写做法，都能增、删、调顺序；配料的用量支持"数字 + 单位"或"适量"；保存后这条菜谱进入数据。

**Blocked by:** 工单 10（录入表单 · 基本信息）

**Status:** ready-for-agent

## 规格要点

- 配料行编辑器：每行 = 食材（搜索选择器，取自食材字典，带"新建食材"入口）+ 用量（数字输入 + 单位下拉：g / ml / 个 / 勺 / 碗 / 斤 / 两 / 根 / 棵 / 片 / 块 / 把）+ "适量"开关（开启后数字与单位禁用置灰）；每行带分类标记（主料 / 辅料 / 调味料）；支持加行、删行、上下移。
- 摆 3 行示例：鸡腿肉 300g（主料）、花生米 50g（主料）、盐 适量（调味料）。
- 步骤行编辑器：每步文本框 + 可选"计时分钟"；支持加步、删步、排序；摆 3 步示例。
- 底部：保存（主按钮）/ 取消（次按钮）；保存写入内存 mock store（静态阶段不做持久化）。
- 长表单整体可滚动，手机视口不溢出。

## 验收标准

- [ ] 配料行：增 / 删 / 上下移、适量开关置灰、单位下拉、新建食材入口齐全
- [ ] 步骤行：增 / 删 / 排序、可选计时
- [ ] 保存后数据进入 store（可在列表里体现）；`npm run build:h5` 通过
