# 06 — 记录列表（含只读浏览）

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 记录 tab：查看做过菜的流水——刚保存的那条在最前 + 一条"随手记"示例；可切"全部 / 按菜谱"视图，点一条看完整只读内容；没有记录时有一句引导。

**Blocked by:** 工单 05（记一笔（做菜记录编辑））

**Status:** ready-for-agent

## 规格要点

- 底部 tabBar"记录"选中态。
- 顶部筛选：全部 / 按菜谱（两种视图：流水列表 / 按菜谱分组）。
- 列表项：日期（"今天"）、菜名（或"随手记"）、版本 chip（"默认版"）、备注摘要。
- 数据：工单 05 保存的那条（宫保鸡丁 · 默认版）+ 预置"随手记"示例（无菜谱、无版本 chip）。
- 点一条记录 → 完整只读视图（复用 05 编辑页样式的只读形态）。
- 空态：无记录时显示"还没有记录，做完一道菜记一笔"（数据驱动 / mock 开关演示）。

## 验收标准

- [ ] 保存的记录出现在列表最前；"随手记"示例无版本 chip
- [ ] 两种筛选视图可切换
- [ ] 只读详情可打开可返回
- [ ] 空态可演示；`npm run build:h5` 通过
