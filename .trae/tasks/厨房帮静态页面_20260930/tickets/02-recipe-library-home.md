# 02 — 菜谱库（首页）

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 打开应用即可浏览菜谱库：看到当前空间名、搜索框、菜系筛选与 7 张真实样本菜卡；卡片可收藏（心形切换）、点击进详情；自家菜带来源标记；含空态提示。

**Blocked by:** 工单 01（工程初始化与全局样式骨架）

**Status:** ready-for-agent

## 规格要点

- 顶部：空间名"老张家的厨房" + 搜索框（占位"搜菜名或食材"）+ 菜系筛选横条（全部 / 川 / 粤 / 浙 / 家常，"全部"默认选中）+ "＋"新建入口（→ 录入表单）。
- 搜索与筛选真实生效（内存过滤）：搜索命中菜名或该菜任一配料食材名；与菜系筛选叠加。
- 列表：单列大卡，组件 `RecipeCard` = 封面图 + 菜名 + 菜系标签 + 耗时 + 难度 + 右上角收藏心形。
- 7 张卡的真实数据（来自 mock）：宫保鸡丁（川 · 30 分钟 · 中等）、麻婆豆腐（川 · 25 分钟 · 简单）、红烧肉（浙 · 90 分钟 · 中等）、清蒸鲈鱼（粤 · 25 分钟 · 中等）、番茄炒蛋（家常 · 10 分钟 · 简单）、青椒土豆丝（家常 · 15 分钟 · 简单）——6 道带"内置"角标；「番茄炒蛋（我家版）」带"我家"标记 + 小字"复制自内置 · 番茄炒蛋"。
- 封面用真实食物图片（落盘 `src/static/cover/`，不用灰块占位）。
- 收藏心形：点击即切换（实心 = 已收藏），状态存 `store`（与工单 12 收藏页同源）。
- 点击卡片 → 菜谱详情（本批目的地为空壳，工单 03 接管）。
- 空态（数据驱动）：自家菜为 0 时只剩内置菜，并显示一句"把常做的菜录进来吧"；用 mock 开关可演示。
- 底部 tabBar"菜谱"选中态。

## 验收标准

- [ ] 7 张卡数据与标注（内置 / 我家 + 来源小字）正确
- [ ] 搜索（菜名 / 食材）与菜系筛选叠加生效
- [ ] 心形可切换；卡片可跳详情（空壳可接受）
- [ ] 空态可通过 mock 开关演示
- [ ] 390px 视口无破版；`npm run build:h5` 通过
