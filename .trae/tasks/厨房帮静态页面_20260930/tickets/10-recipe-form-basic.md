# 10 — 录入表单 · 基本信息

> 参考：[00-总览与约定.md](../00-总览与约定.md) · [design-v0-plan.md](../../../../docs/design-v0-plan.md)

**What to build:** 从首页"＋"或详情"编辑"进入菜谱表单：先把基本信息填起来——封面、名称、菜系、耗时、难度、份量；长表单在手机上滚动不溢出。

**Blocked by:** 工单 03（菜谱详情）

**Status:** ready-for-agent

## 规格要点

- 顶部：标题"新建菜谱"（编辑态为"编辑菜谱"）+ 关闭按钮。
- 封面图上传位（一张食物图 + "换一张"按钮；静态阶段做展示与"换一张"示意即可）。
- 名称输入框（示例内容"红烧排骨"）。
- 菜系 chips：川 / 粤 / 浙 / 家常 / 其它（单选）。
- 耗时（分钟，数字输入）；难度（简单 / 中等 / 较难）。
- 份量：预填"2 人份"，可改、可清空；清空时行内提示"未填份量时不做换算"（样张直接展示该提示态）。
- 除名称外都不必填，保持轻量。

## 验收标准

- [ ] 基本信息字段齐全、菜系 chips 单选可用
- [ ] 份量预填"2 人份"；清空时出现提示文案
- [ ] 关闭可返回上一页；长表单可滚动、390px 无溢出
- [ ] `npm run build:h5` 通过
